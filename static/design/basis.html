The open mathematical and procedural specification every other Vorion property implements. Apache-2.0. Versioned. Conformance-tested. Boring on purpose.

// the role

The substrate everything else stands on.

BASIS is not a product. It is a math+procedure specification — Behavior, Authority, Signature, Integrity, Scope. Cognigate enforces it, AgentAnchor certifies against it, Aurais surfaces it, Kaizen tunes it.

/ 01 The five letters

Each letter is a runtime invariant. An agent action that lacks any one of them does not exist as far as the chain is concerned.

letter
name
invariant
section
BBehaviorThe action's intent and scope are declared before execution and matched at runtime.§ 4.1
AAuthorityThe agent's tier and grant chain are checked against a tamper-evident policy.§ 5.2
SSignatureEvery event is signed by the agent's ed25519 key and counter-signed by the runtime.§ 6.0
IIntegrityEvents form a Merkle chain. Reordering or deletion is detectable in O(log n).§ 7.4
SScopeResource boundaries are declared per-grant and enforced by the runtime gateway.§ 8.1

/ 02 The defining equation

trust(a, t) = Σ i behavior(a, i) · sig(a, i) · Hchain(i) / |scope(a)|

"Trust at time t is the signed-and-chained behavior history, normalized by declared scope." This single line is the only place IBM Plex Serif appears anywhere in the system. It earned it.

/ 03 Who reads basis.spec

// PRIMARY

The implementer

An engineer building a runtime, an SDK, a verifier, or a third-party gateway who needs the math precise enough to write code from.

Don't tell me a story. Give me the state machine, the wire format, and the test vectors.
// SECONDARY

The auditor

Compliance, security review, or external researcher who needs to confirm an implementation matches the spec exactly — and that the spec itself is sound.

Where's the conformance suite? Which vendors have passed which sections?

/ 04 Voice on this property

Spec voice. Numbered sections. MUST/SHOULD/MAY in caps. Footnotes everywhere. No marketing language ever.

Sounds like

"§ 6.0 — Implementations MUST sign every emitted event with an ed25519 key registered to the agent's tier-3 attestation. Implementations SHOULD rotate signing keys at intervals not exceeding 30 days."

Doesn't sound like

"BASIS makes signing easy! Just plug in our SDK and you're chain-of-trust ready in minutes."

/ 05 Mark on this property

The serif B. lockup. Italic, low-saturation, tight tracking. The dot is the only place the violet accent appears on the cover. This is also the only place IBM Plex Serif appears in branding (it normally only shows up inside specifications).
